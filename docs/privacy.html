Privacy Policy — deqlorviewcount

deqlorviewcount is a personal tool used only by its owner on their own YouTube channel.

What data is accessed

Using the YouTube Data API, the app reads the title, description, tags, category and view count of one video owned by the account that authorized it, and updates that video's title.

How data is stored

The OAuth token is stored as an encrypted GitHub Actions secret in the owner's repository. No other personal data is collected, stored, sold or shared with third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
